# REFUEL

## Smart Fuel Navigation for India

REFUEL is a smart fuel navigation platform designed to help users find faster and more convenient fuel stations using real-time crowd data and smart routing.

## Features

- Find nearby fuel stations
- Crowd-powered navigation
- Smart route guidance
- Reduce waiting time at fuel stations
- Save fuel and travel time
- Responsive web interface
- Light and dark theme
- Easy navigation across the platform

## Website Pages

- **Home** — Introduction to REFUEL
- **Features** — Main features of the platform
- **Docs** — Project documentation
- **Download** — App download information
- **Contact** — Contact information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Leaflet.js
