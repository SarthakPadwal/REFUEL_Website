System Architecture

Technical Foundations

A complete technical overview of the REFUEL platform — a production-ready, three-tier system built on Flutter, PHP, and MySQL, powering real-time crowd intelligence across 44,000+ fuel and EV charging stations in India.

flutter
Module 01 / Interface

Flutter Engine

Cross-platform Android and iOS app built with Flutter and Riverpod 2.5. Service-oriented UI with animated 3D vehicle markers, animated bottom navigation, and smooth 60 FPS interactions on every screen.

DART 3.0 RIVERPOD 2.5
database

Core API

PHP 8.2

Secure REST endpoints for auth, stations, crowd sessions, and voting — protected by JWT (HS256) and bcrypt password hashing.

MySQL 8

A 19-table schema with spatial POINT indexing on 44,700+ station records for fast bounding-box and Haversine lookups.

location_on
Spatial Intelligence

GPS & Geofencing

Dual geofencing with a 50-metre entry zone and a 100-metre popup ring. Background GPS pings, cryptographic UUID v4 device IDs, and a 3-reading exit confirmation eliminate false positives and ghost sessions.

map Documentation

OpenStreetMap Integration

Powered by flutter_map 6.1 with OpenStreetMap tiles — no Google Maps API dependency, no vendor lock-in. Colour-coded station pins and crowd-level badges are layered directly onto the map.

APR 2026
Version 1.0.0

Crowd Intelligence Overhaul — Production Release

Vehicle-only crowd counting via SUM(is_vehicle = 1), NULL-safe session binding in exit_station.php, and the adaptive multi-round popup system with self-tuning intervals (MAX(4.0, avg_wait_minutes)). Marked LIVE, DYNAMIC, and FULLY OPERATIONAL.

MAR 2026
Version 0.8.0

Voting & Device Identity Correction

Rewrote DeviceIdHelper to issue a cryptographic UUID v4 per install and purged legacy identifier keys. Fixed availability voting so every vote inserts a fresh row (no more overwrites), and introduced a 5-language preference screen — English, Hindi, Marathi, Tamil, and Telugu.

JAN – FEB 2026
Version 0.1.0 → 0.5.0

Foundation & Crowd System Activation

Initial build covering JWT authentication, OTP with rate limiting, vehicle management (up to 4 vehicles per user), and the 44,700-station data pipeline aggregated from OSM Overpass, GitHub GeoJSON, e-Amrit, and Open Charge Map. Crowd endpoints (enter / ping / exit) went live alongside a bounding-box pre-filter for station lookups.
